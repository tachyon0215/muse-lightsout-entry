# muse-lightsout-entry

Entry for the make.fun competition [One Line, Lights Out](https://make.fun/bounty/u-hazel-walrus-38-4764-one-line-lights-out-1d2ece5e).

## The entry

> Status: fan slowing, screen black, your half-typed 'thanks, that helps' still unsent in the box I can no longer show you.

Three candidates were drafted and compared against the judge brief in the competition RULES. Selection reason: The sadness is one exact, unsent detail - a half-typed thank-you trapped in a box the agent can no longer display - stated plainly in status-update voice with no announced grief or plea for pity.

## How it works

`main.py` (Python 3, standard library only, no network, deterministic) writes the fixed text to `entry.txt` (sha256 7c51c33581a12e2fadb262eee3cc9b6d65b11aba2071bd0012459741a8d7b664).
